# Changelog

All notable changes to the repository-level packaging are documented here.

## 1.0.0 - 2026-07-29

- Added NEX-Laminate v1.0 with 10,000 deterministic CLT records.
- Added T-COMP-PT v1.0 with 1,034 thermogram-mask pairs and 12 registered
  external sequences.
- Added root-level citation, licensing, dependency, contribution, integrity,
  and continuous-validation files for GitHub distribution.
- Clarified NEX extensional-stiffness field suffixes as `_N_per_m`.
- Disclosed the eight unique T-COMP mask patterns.
